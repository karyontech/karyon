# karyon jsonrpc macro

Internal companion crate of
[karyon_jsonrpc](https://crates.io/crates/karyon_jsonrpc): provides the
`#[rpc_impl]` and `#[rpc_pubsub_impl]` procedural macros.

Do not depend on this crate directly; use
[karyon_jsonrpc](https://crates.io/crates/karyon_jsonrpc), which
re-exports the macros.
