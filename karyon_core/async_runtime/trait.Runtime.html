Expand description

A user supplied runtime: runs karyon’s tasks and timers, e.g. a single-threaded executor on WASI. Pass it to karyon as Executor::from(runtime). smol and tokio need none of this; karyon uses their own tasks and timers.

karyon calls schedule each time one of its tasks is woken. Run it with Runnable::run.
