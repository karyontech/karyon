Struct ConfigBuilder 

Source 
pub struct ConfigBuilder {
    config: Config,
}
Expand description

Builds a Config, starting from Config::default(). The fields stay public, so a struct literal works too.

§Example

use karyon_p2p::ConfigBuilder;

let config = ConfigBuilder::new()
    .with_listen_endpoints(vec!["tcp://0.0.0.0:8000".parse().unwrap()])
    .with_dial_peers(vec!["tcp://203.0.113.1:8000".parse().unwrap()])
    .build();
