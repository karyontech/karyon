# karyon eventemitter macro

Internal companion crate of
[karyon_eventemitter](https://crates.io/crates/karyon_eventemitter):
provides the `#[derive(EventValue)]` procedural macro.

Do not depend on this crate directly; use
[karyon_eventemitter](https://crates.io/crates/karyon_eventemitter),
which re-exports the derive.
